# Wine-classification  
🧪 Классификация качества вина


## 📘 Описание проекта

Цель проекта — построить модель машинного обучения, которая классифицирует вино по признакам его химического состава как **вино хорошего качества** (оценка ≥ 7) или **обычного качества** (оценка < 7).

Проект реализован в Jupyter Notebook на Python с использованием библиотеки scikit-learn.  
Основное внимание уделено анализу данных, обработке дисбаланса классов и сравнению алгоритмов классификации.


## 📂 Структура проекта

- Импорт библиотек и загрузка данных  
- Первичный анализ и очистка данных  
- Создание бинарной целевой переменной  
- Визуализация распределений и корреляций  
- Разделение на обучающую и тестовую выборки  
- Построение и сравнение моделей  
- Подбор гиперпараметров  
- Оценка качества и интерпретация результатов

## 🔍 Моделирование

Протестированы несколько алгоритмов классификации:

- Наивный Байес (GaussianNB)  
- Метод k-ближайших соседей (KNN)  
- Метод опорных векторов (SVM)

Финальной выбрана модель **Support Vector Classifier (SVM)**, обученная в конвейере с предварительным масштабированием данных.  
Гиперпараметры подобраны с акцентом на устойчивость к дисбалансу классов.


## 📈 Результаты

Финальная модель (SVM) показала следующие метрики на тестовой выборке:

- **ROC-AUC = 0.80**  
- **F1-score = 0.40**  
- **Precision = 0.54**  
- **Recall = 0.32**

Несмотря на умеренный F1-score, высокое значение ROC-AUC указывает на хорошую способность модели ранжировать объекты по вероятности принадлежности к классу «хорошее качество».  
Низкий recall объясняется сильным дисбалансом классов и может быть улучшен с помощью методов ресэмплинга или настройки порога классификации.
