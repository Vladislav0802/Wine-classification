# Wine-classification
🧪 Классификация качества вина \
📘 Описание проекта

Цель проекта — построить модель машинного обучения, которая классифицирует вино по признакам его химического состава как вино хорошего качества (оценка ≥ 7) или обычного качества (оценка < 7).

Проект реализован в среде Jupyter Notebook на Python с использованием библиотеки scikit-learn.
Основное внимание уделено подготовке данных, анализу признаков и сравнению нескольких классификаторов.

📂 Структура проекта

Импорт библиотек и загрузка данных

Первичный анализ и очистка данных

Создание целевой переменной

Визуализация распределений и признаков

Подготовка выборок (train/test)

Построение и сравнение моделей

Подбор гиперпараметров

Оценка качества и интерпретация результатов

📊 Описание данных

Использован датасет train.csv, содержащий химические характеристики вин, такие как:

fixed acidity — фиксированная кислотность

volatile acidity — летучая кислотность

citric acid — содержание лимонной кислоты

residual sugar — остаточный сахар

chlorides, density, pH, sulphates, alcohol — физико-химические параметры

quality — исходная оценка качества (целое число от 0 до 10)

Для решения задачи была создана бинарная целевая переменная:

df['good_quality'] = df['quality'].apply(lambda x: 1 if x >= 7 else 0)

🧹 Предобработка данных

Удалены пропущенные значения и дубликаты.

Обнаружен дисбаланс классов — вин с высокой оценкой заметно меньше.

Проведен анализ корреляций между признаками — сильная зависимость наблюдалась между alcohol и density.

Признаки нормализованы с помощью масштабирования (MinMaxScaler, StandardScaler, RobustScaler).

🔍 Моделирование
1. Наивный Байес (GaussianNB)

Первая базовая модель, использованная для проверки пригодности признаков.
Показала низкие значения точности на классе "высокое качество", что объясняется сильным перекрытием распределений признаков.

2. Метод K-ближайших соседей (KNN)

Построен Pipeline с масштабированием данных и подбором гиперпараметров:

n_neighbors: 39–49

p: {1, 2, 3}

weights: {‘uniform’, ‘distance’}

Оптимизация по метрике ROC-AUC с помощью GridSearchCV.

Модель показала улучшение метрик по сравнению с Naive Bayes, но всё ещё была чувствительна к шуму и корреляциям между признаками.

3. Support Vector Machine (SVM)

На заключительном этапе была протестирована модель SVM (Support Vector Classifier).
Параметры подбирались с учётом масштабированных данных.
Именно SVM показала наилучшие результаты классификации по метрикам ROC-AUC и F1-score.

🧠 Выводы

Предварительная обработка данных (удаление дубликатов и масштабирование) значительно повысила качество моделей.

Метод опорных векторов (SVM) оказался наиболее эффективным для задачи бинарной классификации качества вина.

Метрика ROC-AUC позволила корректно оценить качество модели на дисбалансных данных.

Визуализации показали, что алкоголь и плотность играют ключевую роль в определении качества вина.
